VLA 학습조직 0주차 — 모델 비교

2026-05-28 회의 자료 · 객관 비교 (우선순위·추천 없음, 선택은 참여자가)

들어가며 — VLA 가 무엇인가

VLA = Vision-Language-Action (시각·언어·행동 통합 모델). 카메라가 본 장면 + 자연어 명령을 입력 받아, 로봇이 해야 할 행동(관절 각도, 그리퍼 등)을 직접 출력하는 거대 모델. "foundation model 의 로봇 버전" 으로 보면 된다. 한 모델을 잘 학습시키면 여러 task / 여러 로봇에 일반화되고, 우리 텔레옵 데이터를 더해 추가 학습(fine-tune)하면 우리 환경에 맞게 적응한다.

VLA 발전 흐름 (간단)

RT-1 (2022, Google) → RT-2 (2023, VLM 도입) → Open X-Embodiment (2023, 표준 데이터셋) → Octo (2024-05) → OpenVLA (2024-06) → RDT-1B / π0 (2024-10) → CogACT (2024-11) → π0 오픈소스화 (2025-02) → GR00T N1.7 (2025-03+) → SmolVLA (2025-06).

두 가지 큰 흐름: (1) 점점 가벼워짐 (7B → 450M), (2) action 표현 진화 (이산 토큰 → diffusion → flow matching).

오늘 회의에서 "1주차부터 어떤 VLA 모델로 학습할지" 를 정하기 위한 비교 자료입니다. 7개 모델을 동등하게 다루며, 최근 가장 많이 사용·인용되는 모델부터 순서대로 정리했습니다 (순서가 곧 우선순위는 아닙니다).

우리 환경 · GPU: NVIDIA RTX 5090 Laptop · 24 GB VRAM · Isaac Lab / Isaac Sim 설치됨 (~/IsaacLab) · 텔레옵 입력: Manus glove (manus_ws), Meta Quest 3 (meta_ws)

2. 모델별 상세

OpenVLA

UC Berkeley / Stanford · 2024-06 (CoRL) · 가장 많이 인용되는 오픈 VLA 베이스라인
크기7B
백본Llama-2 + DINOv2 / SigLIP (Prismatic VLM)
Action 표현이산 토큰 (256-bin). 가속판: FAST (15× 빠름), OFT (25–50× 빠름, 연속 액션)
학습 데이터Open X-Embodiment (97만 궤적)
라이선스MIT (코드), Llama-2 Community License (가중치)
Fine-tuneLoRA 권장 · 권장 VRAM 27GB+ · full FSDP 지원

2024년 이후 발표되는 거의 모든 VLA 논문이 OpenVLA 와 비교한다. 후속 가속판(FAST, OFT)·변형판이 활발해 자료가 가장 풍부하다. 24GB 환경에서는 LoRA 도 마진이 적어 batch size 조정이 필요할 수 있다.

강점 — 자료·예제·튜토리얼 풍부, 후속작 생태계 가장 큼, fine-tune 레시피 정착
제약 — 7B 크기로 무거움, 이산 토큰이라 모션이 거칠 수 있음(OFT 가 완화), 24GB 에서는 LoRA 마진 부족
적용 시나리오
  • 사전학습 weights 로 BridgeData V2 류 task 를 Isaac Lab 에서 재현
  • Manus glove 데이터로 LoRA fine-tune (batch size 조정 필요)
  • OFT 레시피로 추론 가속 실험
🔗 GitHub · 가중치 · 논문

π0 / OpenPI

Physical Intelligence · 2024-10 발표 / 2025-02 오픈소스화 · flow matching VLA 의 대표
크기미공개 (~10B+, 권장 70GB+ GPU)
백본Proprietary VLM + Action Expert (300M)
Action 표현Flow matching (50Hz). π0-FAST: 이산 토큰 버전
학습 데이터자체 로봇 데이터 10,000+ 시간 + ALOHA / DROID
라이선스Apache 2.0
Fine-tuneLoRA 22.5GB · full 70GB+ · 설치 복잡(uv, Git LFS)

오픈된 VLA 중 액션 정교함·실시간성(50Hz)이 최정점으로 평가된다. 오픈소스화 이후 큰 화제. 환경 설정과 GPU 부담이 가장 크며, 일부 가중치는 ALOHA·DROID 같은 특정 로봇 플랫폼에 묶여 있다.

강점 — flow matching 으로 모션 부드러움 · 50Hz 실시간 · Apache 2.0
제약 — 24GB 환경에서는 LoRA 도 빠듯, full 불가 · 설치·실행 진입 비용 높음 · 특정 로봇 플랫폼 의존
적용 시나리오
  • π0-FAST (이산 버전) 만 우선 inference 로 비교 체험
  • flow matching 의 모션 부드러움을 SmolVLA(같은 flow matching, 더 가벼움)와 대조
🔗 GitHub · 발표 블로그

Octo

UC Berkeley · 2024-05 (RSS) · 초기 generalist policy 의 표준 중 하나
크기27M (Small) / 93M (Base)
백본Transformer + 경량 CNN 비전 인코더
Action 표현Diffusion policy (64-step 액션 궤적)
학습 데이터Open X-Embodiment (80만 에피소드)
라이선스Apache 2.0
Fine-tune~16GB · 단일 RTX 4090 에서 200 데모 약 2시간

OpenVLA 의 약 75분의 1 크기로 가장 가벼운 generalist 중 하나. Diffusion policy 라 모션이 부드럽고, 50ms 만에 다음 명령을 출력해 20Hz 실시간 제어가 가능하다. 2024년 초기 표준 중 하나로 인용·비교에 자주 등장.

강점 — 가장 작고 빠른 generalist · Apache 2.0 · 경량 하드웨어 대응 (Jetson 등)
제약 — 출시가 2024-05 라 최신 모델 대비 약간 구버전 · 후속 변형판은 적음
적용 시나리오
  • 경량 하드웨어 배포 시뮬레이션 (Jetson 또는 공장 PC)
  • Diffusion policy 의 "smooth motion" 을 OpenVLA(이산) 와 비교
  • Manus 또는 Quest3 데이터로 빠른 fine-tune 반복
🔗 GitHub · 가중치 · 논문

RDT-1B

Tsinghua University · 2024-10 · 양손(bimanual) manipulation 의 오픈 표준
크기1.2B
백본SigLIP (비전) + T5-XXL (언어) + Diffusion Transformer
Action 표현Diffusion (Physically Interpretable Unified Action Space, 64-step)
학습 데이터OXE 46 데이터셋 (BridgeData V2 포함)
라이선스MIT
Fine-tune~20GB · 새 로봇 플랫폼에 fine-tune 권장

두 팔 로봇(ALOHA 등) 의 협업 manipulation 에 집중한 모델. Diffusion 으로 두 팔의 action 을 동시에 생성한다. 단일 팔 task 에는 과잉이지만, 양손 협업이 필요해지면 거의 유일한 오픈 옵션으로 인용된다. 문서는 논문 중심.

강점 — Bimanual 의 오픈 표준 · 1.2B 로 OpenVLA 보다 가벼움 · MIT
제약 — Colab / 튜토리얼 적음 · 매개변수 설정 복잡 · 단일 팔 task 에는 과잉
적용 시나리오
  • (향후 양팔 setup 도입 시) bimanual fine-tune
  • Diffusion 기반 VLA 의 구조 학습 — inference 체험
🔗 GitHub · 가중치 · 논문

GR00T N1.7

NVIDIA · 2025-03+ · humanoid 로봇용 foundation 모델, Isaac Lab 공식 통합
크기3B
백본Cosmos-Reason2-2B (Qwen3-VL 기반) + Diffusion Transformer
Action 표현Relative EEF (델타 포즈 + 회전 + 그리퍼)
학습 데이터로봇 데이터 + EgoScale (20K 시간 인간 영상)
라이선스Apache 2.0 (N1.7부터)
Fine-tunePosttrain 지원 · 권장 VRAM 24–48GB · Isaac Lab 통합 예제 제공

NVIDIA 가 humanoid 로봇용 foundation 모델로 발표한 시리즈. Action 을 절대 좌표가 아닌 "현재로부터 얼마나 움직일지" (relative EEF) 로 표현해 로봇 종류 간 전이가 용이하다. ~/IsaacLab / ~/isaacsim 과 공식 통합 예제가 존재.

강점 — Isaac Lab 공식 통합 · NVIDIA 공식 튜토리얼 / posttrain 레시피 · 인간 영상까지 학습
제약 — humanoid 특화로 단일 팔/손 task 에는 과잉 · NVIDIA 생태계 의존도 · 24GB 환경에서 batch size 조정 필요
적용 시나리오
  • Isaac Lab 안 wheel_humanoid 14-DoF 모델에 inference
  • Quest3 6-DoF 데이터로 arm posttrain
  • NVIDIA sim-to-real 가이드 참조하여 실로봇 이전 검토
🔗 GitHub · 가중치 · NVIDIA 개발자 페이지

SmolVLA

HuggingFace LeRobot 팀 · 2025-06 · 가장 최신, LeRobot 표준 파이프라인 통합
크기450M (가장 작음)
백본소형 멀티모달 모델 (경량 설계)
Action 표현Flow matching (연속 액션)
학습 데이터LeRobot 커뮤니티 데이터셋 (487개, 10M 프레임)
라이선스오픈 (LeRobot 표준)
Fine-tune~8–16GB · 공식 Colab 노트북 제공 · LeRobot 표준 CLI

HuggingFace LeRobot 팀이 발표한 가장 가벼운 VLA. 큰 모델 대비 30% 빠른 실시간 추론이 특징. LeRobot 라이브러리에 완전 통합되어 데이터 수집·학습·평가가 표준 명령으로 작동한다. 출시는 가장 늦지만 LeRobot 사용자 기반으로 확산이 빠르다.

강점 — 가장 작고 가벼움 · 공식 Colab · LeRobot 표준 파이프라인 · 24GB 환경 매우 여유
제약 — 작은 만큼 복잡 task 일반화는 큰 모델 대비 약함 · 출시가 늦어 외부 인용·사례 아직 적음
적용 시나리오
  • Isaac Lab 가상 로봇으로 Pick & Place inference
  • Quest3 또는 Manus 데이터를 LeRobot dataset 으로 변환 → fine-tune
  • 경량 모델 특성을 살려 여러 task 빠르게 반복 실험
🔗 GitHub (LeRobot) · 가중치 · 논문

CogACT

Microsoft Research · 2024-11 · "인지(Cognition)" 와 "행동(Action)" 을 분리한 아키텍처
크기Small / Base / Large (DiT-S/B/L action head)
백본Prismatic VLM (DINOv2 + SigLIP) + Diffusion Transformer (Action Expert)
Action 표현Diffusion (16-step EEF: XYZ + RPY + grip)
학습 데이터Open X-Embodiment (40만 궤적)
라이선스MIT
Fine-tunefull fine-tune 권장 (LoRA 비권장) · 추론 181ms (A6000)

VLM 이 "Cognition" 토큰만 만들고 별도의 작은 "Action Expert" 가 행동을 출력한다. 두 부분이 분리돼 있어 추론이 빠르고, 행동 모듈만 따로 fine-tune 하는 등 모듈 단위 실험이 가능하다. 학술적 영향력은 있지만 위 모델들 대비 사용량은 적은 편.

강점 — 아키텍처가 명료해 학습 자료로 좋음 · 빠른 추론 · MIT · S/B/L 사이즈 선택
제약 — Colab / 노트북 예제 부족 · full fine-tune 권장이라 학습 부담 일부 큼
적용 시나리오
  • OpenVLA(이산 토큰) vs CogACT(diffusion) action 표현 구조 비교
  • Action Expert 만 교체하는 식의 모듈 단위 실험
  • 작은 사이즈(S)로 full fine-tune 체험

부록 A. 우리 텔레옵 데이터와의 호환성

데이터 소스특징변환 비용이 낮은 모델
manus_ws (Manus glove) 25-key 손가락 관절 + 손목 자세 — hand-focused SmolVLA, Octo, OpenVLA
meta_ws (Meta Quest 3) 6-DoF 손 자세 + 단순 그립 — arm/EEF-focused SmolVLA, OpenVLA, GR00T N1.7

LeRobot 표준 데이터 포맷을 지원하는 모델(SmolVLA, 일부 OpenVLA / GR00T)은 우리 ROS2 bag → LeRobot dataset 변환만 한 번 만들면 재사용 가능. RDT-1B / π0 / CogACT 는 모델별 변환기를 별도 작성해야 한다.

부록 B. 이 자료가 어떻게 만들어졌나

조직장 요청사항 — (1) 비전문가 대상, 가독성 최우선, (2) 대표 오픈소스 VLA 6~7개 비교, (3) 객관 비교 위주, 우선순위·추천 없음, 선택은 참여자가, (4) 자체 텔레옵 데이터로 fine-tune 실습 트랙도 염두, (5) 분량은 너무 길지도 짧지도 않게.
